# E-Commerce Product Management & Shopping System

A web-based **E-Commerce Product Management & Shopping System** that provides a convenient platform for customers to shop online and administrators to manage products, inventory, and orders efficiently.

## ✨ Features

### 👤 Customer Features

* User registration and login
* Browse and search products
* View product details and categories
* Add and remove products from cart
* Place and manage orders

### 🛍️ Shopping Features

* Product catalog
* Category-based browsing
* Shopping cart management
* Order placement
* Product availability tracking

### 🔧 Admin Features

* Add, update, and delete products
* Manage product categories
* Manage inventory and stock
* View and manage customer orders
* Maintain product information

### 🔐 System Features

* User authentication
* Database-driven user id managment
* Responsive and user-friendly interface

**Purpose:** To provide an efficient, organized, and user-friendly solution for online shopping and e-commerce product management.
